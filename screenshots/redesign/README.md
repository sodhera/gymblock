# Actual simulator captures

iPhone 17, iOS 27. Captured from GymBlock during automated simulator journeys and final seeded launch. Sample lifts are marked Demo in the app.

`redesign-01` through `redesign-16` cover Home, free workout search, weight entry, active set, rest, summary, split progress and onboarding. `redesign-24` shows first-time weight selection with no invented load. The `dark-large/` folder uses actual dark appearance, accessibility-large text and increased contrast; its weight-entry, active-set and rest captures are from the final UI.

These are actual app renders. Earlier captures in the parent folder document the previous design. See ../../VALIDATION.md for test provenance and verification limits.
